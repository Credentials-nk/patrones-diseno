# 04.2-decorator

Este ejemplo muestra el patrón de diseño **Decorator** aplicado en TypeScript. El patrón Decorator permite añadir funcionalidades adicionales a un objeto de manera dinámica, sin modificar su estructura original.

## Diagrama de clases


```
                   ┌──────────────────────────┐
                   │      Character (iface)   │
                   │  getDescription()        │
                   │  getStats()              │
                   └───────────┬──────────────┘
                               │
                               ▼
                 ┌───────────────────────────┐
                 │      BasicCharacter       │
                 │ "Personaje básico"        │
                 │ atk:10  def:10            │
                 └───────────┬───────────────┘
                             │
                             ▼
                 ┌───────────────────────────┐
                 │    CharacterDecorator     │
                 │  (envoltorio genérico)    │
                 │  delega en: this.character│
                 └───────────┬───────────────┘
      ┌──────────────────────┼─────────────────────────┐
      ▼                      ▼                         ▼
┌───────────────┐   ┌────────────────┐       ┌──────────────────┐
│ HelmetDecorator│   │ShieldDecorator│       │ SwordDecorator    │
│ +defense: +5   │   │+defense: +10  │       │+attack: +7        │
└───────────────┘   └────────────────┘       └──────────────────┘
                              │
                              ▼
                  ┌──────────────────────────┐
                  │     RingDecorator        │
                  │     +attack: +3          │
                  └──────────────────────────┘


FLUJO FINAL DEL PERSONAJE (encadenamiento):

BasicCharacter
      ↓
HelmetDecorator
      ↓
ShieldDecorator
      ↓
SwordDecorator
      ↓
RingDecorator

```


## Explicación
- `Componente`: Interfaz base.
- `ComponenteConcreto`: Implementación concreta.
- `Decorador`: Clase abstracta que referencia a un componente.
- `DecoradorConcretoA/B`: Decoradores específicos que agregan funcionalidad.

Las flechas indican herencia o referencia. Los decoradores envuelven al componente y pueden encadenarse.

## Uso
Puedes instanciar un `ComponenteConcreto` y envolverlo con uno o varios decoradores para añadir funcionalidades de forma flexible.
